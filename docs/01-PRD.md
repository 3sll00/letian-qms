## 1. 系统业务目标与核心价值

乐天紧固件作为专业工业紧固件制造企业，产品广泛应用于汽车、高铁、机械制造等领域，对尺寸公差（通常要求在 ±0.02mm 甚至微米级）、表面热处理硬度、镀层膜厚以及金相化学性能有着极其严苛的标准。本系统（Letian QMS）的核心目标包括：
1. **标准与方案数字化**：支持按分类批量制定质检方案、多维度指标项（外观/尺寸/机械性能/化学成分等）与抽样规则线上化，杜绝经验口传；
2. **强制放行阻断 (MANDATORY_GATE)**：在成品检、出货等关键卡点实行系统级物理阻断，未检/不合格批次严禁入库流转或出库发货；
3. **闭环不合格评审 (MRB)**：不合格品判定即自动进入多级可配置评审流程（退货/返工/特采/报废），不合格记录同步留痕于不合格台账，全流程留痕；
4. **全链路批次与炉批追溯**：以批次号（Lot/Batch No）及炉批号（Heat No）为关键维度，打通委外热处理与来料检验历史，实现端到端全生命周期追溯；
5. **高度可扩展系统集成**：针对管家婆 ERP（财贸版 SQL Server）无开放 API 现状，建立基于数据库直连与单据原生“选单下推”链路的双向数据中枢；卖系统预留 Outbox Sink 回写通道；
6. **多模板灵活报表打印**：支持四段式质检报告分段/全段打印与多模板自选导出，满足不同客户与出口标准的个性化报告需求。

## 3. 核心业务规格与详细规则定义

### 3.1 质量总览 (Dashboard)
- **检验进度总览 [WPS图片(1)]**：
  - 核心指标卡片：总检验单数、综合合格率（%）、待检工单数、MRB待审及处置中数量、今日新增检验数；
  - 统计图表：IQC/IPQC/OQC 阶段分布环形图、质量合格率趋势折线图、前5项高频不良物料横向柱状图；
  - 动态任务流：滚动显示最新检验与审核任务，异常项红色高亮。
- **检验进度明细 [WPS图片(11)] 与高级多次筛选**：
  - 跨检验类型（IQC/IPQC/OQC/委外）集中展现进度状态；
  - **PC 端高级筛选器规范**：
    1. 支持多条件组合逻辑（AND 关系拼接）；
    2. 支持单一维度字段的多选过滤（如：同时勾选“螺栓、螺母”两个分类；同时多选 3 家供应商）；
    3. 支持将当前组合条件保存为“常用筛选方案”，便于高频调取；
  - **导出能力**：支持按当前筛选结果导出为 PDF 报告、CSV 数据表、Excel 台账。
- **质量追溯看板 [WPS图片(12)]**：
  - 批次与炉批全景追溯链（原材料炉批号/来料批次 -> 工序流转 -> 委外热处理/表面处理 -> 销售出货）；
  - 支持双向追溯（客户投诉反查、原材料缺陷正向影响评估）；
  - 异常节点红色警示，支持一键生成并导出《批次质量追溯全景报告》。

### 3.2 IQC 来料检验 (Incoming Quality Control)
- **列表与管家婆 ERP 对接 [WPS图片(2)]**：
  - 自动从管家婆 ERP（财贸版 SQL Server）读取采购送检单数据；
  - 自动根据物料编码/所属存货分类快照匹配生效的质检方案；
  - 列表支持状态筛选、供应商多选、日期范围筛选。
- **检验录入与指标规范 [WPS图片(3)]**：
  - 逐项展示标准指标、公差要求及检测工具；
  - **化学成分多元素录入**：支持录入原材料关键化学成分（C、Si、Mn、P、S、Cr、Ni 等），系统自动对比标准区间；
  - **机械性能录入**：支持录入抗拉强度、硬度等实测值；
  - 录入抽样数量与实测值，系统自动判断单项与综合合格状态；
  - 录入“检验备注”与“综合结论”；判定为不合格时强制上传缺陷照片；
  - **业务流转**：检验判定为不合格的单据，数据自动流入“MRB 不合格品待审核池”，不直接粗暴建单。
- **管家婆 ERP 采购检验单回写**：
  - 检验结单后，系统遵循管家婆原生“单据选单下推”逻辑，在管家婆数据库中生成对应的“采购检验单”，保留原始送检单的上游关联键，确保财务与仓储业务闭环。

### 3.3 IPQC 过程检验 (In-Process Quality Control) 与强制放行关卡
- **三工序概览 [WPS图片(4)]**：下料 (IPQC-CT)、滚丝 (IPQC-RL)、成品检 (IPQC-FN) 三卡片入口，展示今日汇总与 MES 同步状态。
- **工序检验与抽检免检 [WPS图片(5), (6)]**：
  - **三页台账列集（原型图实测口径，图 5/6/7）**：三页均为 **11 列**，仅「工序专有列 / 检验人 / ★ 关卡」三处分叉：
    - 下料检验（IPQC_CT）：`检验单号 | MES工单号 | 物料编码 | 物料名称 | 数量 | 断料长度 | 操作员 | 设备 | 完成时间 | 状态 | 操作`；
    - 滚丝检验（IPQC_RL）：`检验单号 | MES工单号 | 物料编码 | 物料名称 | 数量 | 操作员 | 设备 | 完成时间 | 状态 | 检验人 | 操作`，关联 MES 车间生产批次与本工序报工时间；
    - 成品检（IPQC_FN）：`检验单号 | ★ | MES工单号 | 物料编码 | 物料名称 | 数量 | 终检组 | 完成时间 | 状态 | 检验人 | 操作`，★ = 强制检关卡（`is_mandatory_gate`）。
    三页「操作」列按状态分派【检验】/【继续】（成品检「检验中」）/【详情】；列 × 字段 × 接口对照见 `docs/29` §2 与 `docs/30` §2。
  - **“不解检（EXEMPT）”标记逻辑**：
    1. 过程抽检样本默认处于全选报检状态；
    2. 质检员可根据车间工艺规程，对特定免检样本或免测指标标记为“不解检”；
    3. 被标记为“不解检”的项目不纳入合格率分母计算，状态标识为灰色“免检”；
    4. 系统强制记录不解检操作人、操作时间与原因，计入操作审计日志。
- **成品检强制物理阻断关卡 (MANDATORY_GATE) [WPS图片(7)]**：
  - 带有醒目的`强制检验`标识，未完成检验或检验不合格批次严禁入库与流转；
  - **MES 只读放行校验接口**：`GET /api/v1/release-gates/{batchNo}` 纯读无副作用，返回 409 阻断并附带原因代码（`GATE_NOT_INSPECTED`, `GATE_INSPECTING`, `GATE_FAILED`, `GATE_UNDER_MRB`）；
  - **MES 异步锁定推送**：通过 Transactional Outbox 推送 `BATCH_LOCKED` 事件，MES 消费端基于 `eventId` 去重并物理闭锁机台。

### 3.4 OQC 委外检验 (七分类与外部数据挂载)
- **委外七分类工作台 [WPS图片(8) 升级版]**：
  - 界面提供七大工艺分类 Tab：**热处理、发黑、镀锌、镀镍、磷化、达克罗、机加工**；
  - 支持按分类集中展示与检索外协批次；
- **外部 13 张表数据挂载逻辑**：
  - 委外数据来源于外部协作方数据库（13 张业务表），本系统无原始生成单据；
  - 系统通过集成中枢定时从外部数据库拉取外协批次、工艺要求及扫码落位标识，在 QMS 委外工作台中完成自动挂载；
- **检验结果分类分流回写**：
  - 质检员在对应分类 Tab 下录入膜厚、硬度、外观等实测结果；
  - 检验完成后，系统根据数据所属工艺类型（如热处理 vs 镀锌），将检验参数与合格结论分流回写至外部数据库的对应目标表与位置中，支持落位规则的灵活配置。

### 3.5 OQC 出货检验与炉批号智能追溯
- **列表与出库阻断 [WPS图片(9)]**：
  - 关联客户档案与销售发货单（支持读取卖系统发货单数据）；
  - 具有发货出库前阻断权：未检或不合格禁止出具 COA 质检证书。
- **炉批号智能联动机制 (核心创新)**：
  - 出货检验录入炉批号（Heat No）时，系统自动触发两级历史溯源链路：
    1. **第一优先级**：自动检索该炉批号对应的【委外检验 - 热处理分类】已结单记录，自动带出当时检验的抗拉强度、洛氏硬度、淬硬层深度等机械性能实测数据；
    2. **第二优先级**：若委外热处理无此炉批号记录，系统回退检索该炉批号对应的【IQC 来料检验】记录，带出原材料化学成分（C, Si, Mn...）及材质力学指标；
    3. **第三优先级**：若两处均无历史记录，界面显示“未匹配到历史炉批数据”，允许质检员现场完全手工录入；
  - **手工修改与审计防伪**：
    - 联动带出的历史数据允许质检员在出货单中手工修正；
    - 系统强制保留原始继承快照（`inherited_snapshot`），将该项标记为 `is_manually_modified: true`，并在操作日志中记录修改人、修改前后值与修改说明，保证追溯证据链不可抵赖。
- **出货录入与 COA 质检报告 [WPS图片(10)]**：
  - 动态指标录入与 AQL 抽样判定；
  - 支持检验草稿暂存与正式提交。

### 3.6 不合格品处置与评审流程 (MRB)
- **【判定即入评审 + 单页承载】不合格品处置机制**（2026-09-23 口径变更，详见 `43-不合格判定自动发起MRB评审设计.md`）：
  - IQC、IPQC、委外检验、OQC **判定不合格即自动创建 MRB 评审单**并进入多级会签，与终判**同一事务**提交，**全程无人工发起环节**；来源分类按环节自动判定（来料 `INCOMING_FAIL` / 过程 `PROCESS_FAIL` / 委外 `SUBCONTRACT_FAIL` / 出货 `SHIPMENT_FAIL`）并绑定对应生效评审流程（逐环节对照表见 `44-过程委外出货不合格自动进MRB口径补齐设计.md` §1）；
  - 菜单只保留两项（对齐客户确认清单第 10、11 项）：**MRB不合格品处置** 与 **评审流程设置**；
  - **阶段 1：不合格台账 (Pending Review Pool) — 自动汇入、只读留痕**
    - IQC、IPQC、委外检验、OQC 判定不合格的记录，全量自动汇总至“不合格待审核池”台账；
    - 各检验环节数据相互独立，不跨环节合并计算；
    - 台账字段：来源检验单号、检验环节、物料编码、规格、批次号、不合格项目、不合格数量、发现人、发现时间；
    - 台账**不承载任何人工动作**：条目在自动建单时即置为“已入评审”并回填 MRB 单号，供追溯、审计与集成查阅。
  - **阶段 2：MRB 评审与决策流转 [WPS图片(13)] — 主页面处置列表**
    - 系统根据不合格类型（来料/过程/出货/委外）**自动绑定**对应的生效评审流程（FL-001等）；
    - 顶部 5 项 KPI：待评审、评审中、已评审、已处置、本月评审率；
    - 筛选栏：MRB单号、来源检验单、评审状态、处置方式、日期；
    - 4 个状态页签：待评审 / 评审中 / 已评审 / 已处置；
    - 处置列表十列：MRB单号、来源检验单、物料编码、物料名称、不合格原因、不合格数量、检验人、发现日期、评审状态、操作；
    - 行内【评审】打开“评审与处置”抽屉：四方签核进展 + 电子签核 + 处置结论提交；
    - 4 大处置决策分支：
      1. **退货 (Return)**：生成退货判定单，通知仓库与采购退料；
      2. **报废 (Scrap)**：物料报废，生成报废确认书；
      3. **特采 / 让步接收 (Concession)**：必须由技术部门与客户代表联合双签，附带特采审批书；
      4. **返工 / 返修 (Rework)**：状态机回边，自动生成复检轮次工单（第 N+1 轮）；
    - **超时催办**：超过 24 小时未决策的评审单，系统红标告警并发送催办提醒。
- **评审流程设置 [WPS图片(14)]**：
  - 支持用户可视化配置 1~3 级审批节点与审批责任角色；
  - 支持按来料、过程、出货、委外分别配置独立流程，支持启用/停用/版本克隆。
- **详细口径**：状态/KPI 定义、字段映射与接口清单见 `docs/19-MRB不合格品处置页整合设计.md`。

### 3.7 质检方案管理与分类批量配置
- **按分类批量配置方案 (核心提效)**：
  - 支持以“存货分类”为主体制定标准方案模板（如“碳钢高强度螺栓类”）；
  - 配置时支持设置方案名称、检验项目、公差要求、测量工具、AQL抽样标准；
  - 支持设置方案有效周期（生效起始日期 - 失效日期）；
  - **分类继承机制**：该分类下的所有物料默认继承所属分类方案，无需逐个物料单独建单；对于有定制公差要求的特殊料号，允许单独维护物料级覆盖方案；
  - 支持在方案列表中按分类快速勾选物料进行批量应用或批量更新。
- **六维检验指标体系**：
  1. `DIMENSION`：尺寸检验（公差带上下限数值型）；
  2. `APPEARANCE`：外观检验（定性描述/合格项勾选）；
  3. `MECHANICAL_PERFORMANCE`：机械性能（抗拉、屈服、伸长率等）；
  4. `CHEMICAL_COMPOSITION`：化学成分（C, Si, Mn, P, S, Cr 等多元素百分比矩阵）；
  5. `HARDNESS`：硬度检验（HRC, HV, HB 等）；
  6. `COATING_THICKNESS`：膜厚检验（镀层微米厚度）。
- **方案快照强绑定**：检验单创建时深拷贝当时的生效方案版本（主表 JSONB 快照 + 明细物理表），历史单据不受后续方案变更影响。

### 3.8 质检报告打印与多模板管理 (独立报表子系统)
- **报告四段式标准结构**：
  - 紧固件出厂检验报告标准化为四段：
    1. **第一段：外观检验**（表面光洁度、裂纹、毛刺、螺纹完整性）；
    2. **第二段：尺寸检验**（螺纹大径、中径、小径、总长、六角对边等）；
    3. **第三段：性能检验**（抗拉强度、保证载荷、硬度、金相组织）；
    4. **第四段：化学成分**（材质材质牌号、C/Si/Mn/P/S 等主要化学元素分析实测值）。
- **列表打印交互规范**：
  - 在来料、过程、委外、出货等检验列表页，提供全局**【打印质检报告】**操作按钮；
  - 点击后弹出**“模板选择与打印参数设置”**弹窗：
    1. **模板选择**：支持下拉选择适用模板（如：通用紧固件报告模板、委外专用报告模板、客户定制英文报告模板等）；
    2. **打印范围**：支持勾选全部打印或分段独立打印（外观/尺寸/性能/化学成分独立分页）；
    3. **导出格式**：支持直接在线调起浏览器打印预览，或导出为矢量 PDF / Excel 文件；
    4. **批量导出**：支持设置日期范围（起止时间）与单据状态，批量打包导出质检报告。
- **模板管理中心**：
  - 支持维护多套报告模板元数据与样式定义；
  - 来料、过程、成品、出货默认共用通用标准模板；委外检验使用委外专用模板；支持新增客制化模板。

### 3.9 基础档案与 PBAC 数据权限
- **存货分类树 [WPS图片(18)]**：树形结构维护，支持增删改查与 CSV 批量导入；
- **ERP 基础档案全面拉取 [WPS图片(16), (17), (19)]**：
  - 自动从管家婆 ERP 数据库读取 6 类基础档案：供应商、客户、存货、仓库、车间、职员；
  - 供应商与客户档案必须拉取完整名称、联系人及属性，杜绝仅有编码导致的显示异常。
- **物料数据权限管控 (PBAC) [WPS图片(20)]**：
  - 三维安全隔离：**物料编码、存货分类、供应商**；
  - 支持按岗位/角色划分查看范围（例如：张三仅可查看指定的 3 类物料与对应供应商，无成品与其余分类查看权限）；
  - 配套“权限校验日志”Tab，保留 180 天查询拦截日志。

### 3.10 系统集成与审计日志
- **管家婆 ERP 集成中枢 (SQL Server 直连)**：
  - 专职适配器：读取采购送检单、拉取 6 类基础档案；
  - 选单下推：检验结单后生成管家婆采购检验单据并挂载源单关联；
- **卖系统数据集成通道**：
  - 一期：直接从卖系统数据库只读读取客户订单/发货数据，本地记录检验参数，不向卖系统反向同步合格数量；
  - 二期扩展性：通过 Transactional Outbox 预留回写事件流，预留可插拔回写 Sink；
- **操作审计日志 [WPS图片(21)]**：
  - 记录删除、检验录入、判定提交、炉批修改、评审审批等全量操作；
  - 数据库底层行级触发器防护，严禁任何 UPDATE 或 DELETE 操作。
