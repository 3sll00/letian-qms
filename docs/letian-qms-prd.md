## 1. 系统业务目标与核心价值

乐天紧固件作为专业工业紧固件制造企业，产品广泛应用于汽车、高铁、机械制造等领域，对尺寸公差（公差带通常要求在 ±0.02mm 甚至微米级）、表面热处理硬度及镀层膜厚有着极高的精密要求。本系统（Letian QMS）的核心目标包括：
1. **检验标准数字化**：实现质检方案、指标项、公差带与 AQL 抽样规则的全面线上化，杜绝经验口传；
2. **强制放行阻断 (MANDATORY_GATE)**：在成品检、出货等关键卡点实行系统级物理阻断，未检/不合格批次严禁入库流转或出库；
3. **闭环不合格评审 (MRB)**：不合格品自动触发可配置的多级评审工作流（退货/返工/特采/报废），全流程留痕；
4. **全链路批次追溯**：以批次号（Lot/Batch No）为核心维度的端到端全生命周期追溯；
5. **系统集成与信息消除**：无缝对接管家婆 ERP 基础档案与 MES 车间生产工序数据，消除数据孤岛。

## 3. 核心业务规格与详细规则定义

### 3.1 质量总览 (Dashboard)
- **检验进度总览 [WPS图片(1)]**：
  - 核心指标卡片：总检验单数、综合合格率（%）、待检工单数、MRB处置中数量、今日新增检验数；
  - 统计图表：IQC/IPQC/OQC 阶段分布环形图、质量合格率趋势折线图、前5项高频不良物料横向柱状图；
  - 动态任务流：滚动显示最新检验与审核任务，异常项红色高亮。
- **检验进度明细 [WPS图片(11)]**：
  - 跨检验类型（IQC/IPQC/OQC/委外）集中展现进度状态（待检、检验中、审核中、已完成）；
  - **导出能力支持**：支持筛选结果一键导出为 **PDF 报告、CSV 数据表、Excel 台账**。
- **质量追溯看板 [WPS图片(12)]**：
  - 批次全景追溯链（原材料批次 -> 工序流转 -> 委外加工 -> 销售出货）；
  - 支持双向追溯（客户投诉反查、原材料缺陷正向影响评估）；
  - 异常节点红色警示，支持一键生成并导出《批次质量追溯全景报告》。

### 3.2 IQC 来料检验 (Incoming Quality Control)
- **列表与详情 [WPS图片(2), (3)]**：
  - 关联 ERP 供应商档案与原材料入库单；
  - 自动快照匹配生效的质检方案，逐项展示标准指标、公差要求及检测工具；
  - 录入抽样数量与实测值，系统自动判断单项与综合合格状态；
  - 包含**“检验备注”与“综合结论”**文本录入域；判定为不合格时强制上传缺陷照片并自动触发 MRB。

### 3.3 IPQC 过程检验 (In-Process Quality Control) 与强制放行关卡
- **三工序概览 [WPS图片(4)]**：下料 (IPQC-CT)、滚丝 (IPQC-RL)、成品检 (IPQC-FN) 三卡片入口，展示今日汇总与 MES 同步状态。
- **工序检验 [WPS图片(5), (6)]**：
  - 下料检验：11 列表格（工单号、物料编码、规格型号、批次号、工序号、工序名称、检验类型、抽检数、合格数、状态、操作），弹窗录入，超差红色高亮。
  - 滚丝检验：关联 MES 车间生产批次，标准值参考。
  - **共享检验指标体系澄清**：下料、滚丝、成品检各自绑定对应工序的检验方案，但**统一复用同一套指标公差判定引擎与实测值录入 UI 组件库**。
- **成品检强制物理阻断关卡 (MANDATORY_GATE) [WPS图片(7)]**：
  - 带有醒目的`强制检验`标识，未完成检验或检验不合格批次严禁入库与流转；
  - **MES 同步只读校验接口**：`GET /api/v1/release-gates/{batchNo}` 纯读无副作用，返回 409 阻断并附带原因代码：
    - `GATE_NOT_INSPECTED`：未发起成品检验，阻断机台；
    - `GATE_INSPECTING`：成品检验进行中，尚未出具最终判定；
    - `GATE_FAILED`：成品检验不合格，机台物理闭锁；
    - `GATE_UNDER_MRB`：批次处于 MRB 评审中，处于质量冻结状态。
  - **MES 异步锁定通知**：通过 Transactional Outbox 推送 `BATCH_LOCKED` 事件（带唯一 `eventId`），MES 端基于 `eventId` 去重并冻结在制品批次。

### 3.4 OQC 委外检验 [WPS图片(8)]
- 三大委外分类 Tab：**表面处理（镀锌/镀镍/发黑/磷化）、机加工、热处理**；
- 关联 ERP 委外加工单与 MES 外协工序；
- 检验膜厚、硬度、外观等关键外协指标；
- 异常闭环流转至 MRB 委外评审流程，支持退回复镀或报废；*(注：涉及供应商扣款结算由 ERP 财务模块处理，QMS 输出判定单据)*。

### 3.5 OQC 出货检验 [WPS图片(9), (10)]
- 关联客户档案与销售发货单；
- 动态指标录入与 AQL 抽样判定；
- 具有出库前阻断权：未检或不合格禁止出具 COA 质检证书与 ERP 出库审核；
- 支持检验草稿暂存与正式提交。

### 3.6 MRB 不合格品评审与流程引擎 [WPS图片(13), (14)]
- **MRB 处置列表 [WPS图片(13)]**：
  - 顶部 5 项 KPI：待评审、评审中、已评审、已处置、本月评审率；
  - 4 类快速过滤 Tab：`待评审`、`评审中`、`已评审`、`已处置`；
  - 列表字段：MRB单号、来源检验单、物料编码、物料名称、不合格原因、不合格数量、检验人、发现日期、评审状态、操作；
  - 四大处置方式：退货 (Return)、返工 (Rework，触发状态机回边生成复检轮次)、让步接收/特采 (Concession，定制件强制要求技术部与客户代表联合签核)、报废 (Scrap)。
- **评审流程设置（可配置流程引擎）[WPS图片(14)]**：
  - 4 栏统计：流程总数、已启用、待处理评审、已完成评审；
  - 筛选栏：流程名称、适用类型下拉（`来料不合格`、`过程不合格`、`出货不合格`、`委外不合格`）、状态下拉（`全部`、`已启用`、`已停用`）；
  - 列表字段：流程编号（如 FL-001）、流程名称、适用类型、评审节点数（如 1级/2级/3级）、状态（已启用/已停用）、创建人、创建时间、操作（编辑/停用/启用/删除）；
  - **核心能力**：**非硬编码，支持用户可视化配置多级审批节点与责任角色**。当 IQC/IPQC/OQC 提交判定为“不合格”时，系统根据不合格类型自动匹配对应的有效流程实例并启动流转；
  - 超过 24 小时未决策自动触发系统级超时催办与标红警示。

### 3.7 质检方案与指标库 [WPS图片(15)]
- 方案分为四大类（来料/过程/出货/委外），绑定物料编码与存货分类；
- 状态机包含 `DRAFT`（草稿）、`ACTIVE`（已启用）、`INACTIVE`（已停用）；
- **方案快照强绑定**：检验单创建时深拷贝当时的生效方案版本（主表 JSONB 快照 + 明细行物理表），后续方案升版严禁篡改历史单据判定基准；
- 包含数值型公差带（±公差、上下限）及文本型区间判定，集成 GB/T 2828 / AQL 抽样规则。

### 3.8 基础档案、数据权限与系统集成 (对齐确认文档第 15-21 项)
- **存货分类 [WPS图片(18)]**：树状层级展示，支持节点增删改及 CSV 批量导入；
- **ERP 基础档案总览与同步 [WPS图片(16), (17), (19)]**：
  - **六类档案全面同步**：供应商档案、客户档案、存货物料档案、**仓库档案、车间档案、职员档案**（为 IPQC 工序机台归属与 MRB 审批人绑定提供完整主数据源）；
  - 支持编码与名称模糊检索、分页展示。
- **物料数据权限管控 (PBAC) [WPS图片(20)]**：
  - 三维安全隔离：**物料编码、物料分类、供应商**；
  - 支持按角色（IQC/IPQC/OQC检验员、主管等）批量赋权；
  - **权限校验日志 Tab**：记录每次敏感数据查询时的行级过滤与拦截情况，日志存储于 `authorization_logs` 表，保留周期至少 180 天。
- **系统操作审计日志 [WPS图片(21)]**：
  - 汇总统计卡片：操作日志总数、成功操作、失败/异常、今日操作；
  - 全程记录关键操作：来料/出货提交、方案变更、MRB评审审批、ERP/MES同步；
  - **失败操作红色高亮告警**，操作日志具备数据库触发器禁止篡改。
- **MES 集成管理配置中枢 (确认文档第 21 项)**：
  - 提供可视化的车间生产数据对接配置界面：
    1. MES 服务通信地址与认证 Token 配置；
    2. 对接车间与对接工序勾选（下料车间、滚丝车间、热处理等）；
    3. 同步频率设置（如 5分钟轮询或实时 Webhook 监听）；
    4. 一键手动触发全量/增量同步与测试联通性按钮；
    5. 同步批次状态监视、失败原因查看与断点重试。
