## 2. 管家婆 ERP (SQL Server) 深度直连方案

### 2.1 连接模式与只读安全原则
- **安全铁律**：QMS 严禁直接使用 `sa` 或具备写入权限的账号直连 ERP 生产数据库。
- **视图解耦架构**：在 ERP SQL Server 数据库中创建专用只读只查视图（前缀 `vw_qms_*`），并为其分配独立的只读数据库用户 `qms_sync_user`。
- **核心视图清单**：
  1. `vw_qms_ptype`：存货档案视图（映射字段：存货代码 `type_code`、品名 `type_name`、规格 `spec`、计量单位 `unit`、所属分类代码 `category_code`）。
  2. `vw_qms_btype`：往来单位视图（映射字段：往来单位编号、单位名称、性质：供应商/客户）。
  3. `vw_qms_cg_arrival`：采购到货待检单视图（映射字段：采购订单号、到货单号、供应商代码、物料代码、到货数量、采购批号、约定交期）。
  4. `vw_qms_sc_order`：车间生产工单视图（映射字段：工单编号、产品代码、计划产量、工单状态、派工班组）。

## 4. 车间 MES 与生产关卡拦截钩子 (Release Gate Hooks)

### 4.1 生产阻断拦截调用流程
1. 车间机台终端或工序报工扫码枪扫描流转卡二维码（包含工单号 `WO-XXXX` 与当前工序 `P03`）。
2. 车间 MES 在提交报工结转前，通过 HTTP 内部 RPC 同步调用 QMS 放行关卡：
   ```http
   GET /api/v1/release-gates/check?work_order_no=WO-XXXX&process_code=P02
   ```
3. **QMS 判定内核**：
   - 检索 `work_order_no = WO-XXXX` 且 `process_code = P02` 的最新检验单。
   - 若不存在记录 -> 判定 `BLOCKED`，拦截报工。
   - 若状态为 `FAIL` 且未完成 MRB 终审特采 -> 判定 `BLOCKED`，拦截报工。
   - 若状态为 `PASS` 或 `CONCESSION` -> 判定 `RELEASED`，放行结转。
4. **ERP 入库关卡拦截**：
   在管家婆 ERP 审核采购入库单或产成品入库单时，配置数据库触发器或前置插件调用 QMS 关卡，确保未检验合格批次物理上无法入库。

## 5. 同步调度、容错重试与断路器策略

### 5.1 同步定时任务设计 (Cron Schedules)
- **基础档案全量定时同步**：每 30 分钟一次（`0 */30 * * * *`），增量比对存货分类与物料更新。
- **采购到货与工单准实时同步**：每 3 分钟一次（`0 */3 * * * *`），拉取最新待检单据。
- **Outbox 事务发件箱轮询**：每 5 秒一次（`*/5 * * * * *`），异步分发业务放行与状态通知。

### 5.2 容错重试与断路器 (Resilience & Circuit Breaker)
- **网络抖动与数据库短暂不可用**：采用指数退避重试（1s -> 5s -> 30s -> 5min），最大重试 5 次。
- **ERP 停机维护与断路器**：连续失败达到 10 次时，熔断器打开，暂停主动拉取，并向质量系统管理员发送报警通知，系统本地离线缓存继续提供服务，待连接恢复后自动重放补录。

## 4. 数据库环境准备与连接池配置指南 (Database Setup & Pool Config)

### 4.1 PostgreSQL 生产主库初始化
> 本机（开发机）PostgreSQL 实例的**启停方式、数据目录与端口口径（固定 `5432`，历史端口 `55432` 已废弃）**见
> [`23-本地数据库运行手册与端口口径.md`](./23-本地数据库运行手册与端口口径.md)；本节只讲生产库初始化与连接池参数。

1. **字符集与排序规则**：必须使用 `UTF8` 编码，Collate `zh_CN.UTF-8` 或 `C`。
2. **连接池建议**：
   - 生产环境建议通过 PgBouncer 或 Kysely 驱动内建连接池（`min: 5, max: 20`）。
   - 空闲超时：`idleTimeoutMillis: 30000`，连接超时：`connectionTimeoutMillis: 5000`。
3. **数据库迁移指令**：
  ```bash
  pnpm db:migrate          # 迁移到最新版本（等价 pnpm --filter @letian/infrastructure run migrate:up）
  pnpm db:migrate:down     # 回退最近一次迁移（单步回退，用于验证迁移可逆）
  pnpm db:seed             # 播种演示数据（会清表重建，仅用于开发 / 演示环境）
  ```

### 4.2 管家婆 ERP (SQL Server) 只读数据源配置
1. **驱动协议**：采用 TDS (Tabular Data Stream) 协议，使用只读账号直连管家婆账套库。
2. **连接防死锁配置**：
   - 所有查询强加 `WITH (NOLOCK)` 查询提示，杜绝因 QMS 报表统计拉取导致 ERP 业务开单阻塞。
   - 查询超时严格设为 `10000ms`。

## 4. 单据勾稽链路与 QMS 质量放行关卡对接方案

### 4.1 采购来料检验 (IQC) 业务闭环
1. **采购订单**：DlyNdxOrder (VchType=150) + BakDlyOrder。供应商按采购合同发货到厂。
2. **采购送检单**：DlyNdxCheck (VchType=146) + DlyCheck。QMS 读取待检批次（物料规格/炉批号/送检量）。
3. **QMS 检验判定**：检验员录入理化实测数据并判定：合格/特采/退货。
4. **采购检验单**：DlyNdxCheck (VchType=147: JHJY-*) + DlyCheck。判定结果写入 ERP 检验单。
5. **质检关卡拦截**：ERP 采购入库单 (DlyNdx + DlyBuy, VchType=161, GR-*) 严格依赖检验合格单，无合格凭据禁止入库。

### 4.2 生产任务与委外工序检验 (IPQC / FQC) 业务闭环
