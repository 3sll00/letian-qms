## 1. 物理数据库全景概览 (22+ 实体表)

数据库划分为 7 大物理功能分区，全部采用 `snake_case` 命名规范，外键强约束与 JSONB 扩展灵活并存：

```
┌────────────────────────────────────────────────────────────────────────┐
│                     PostgreSQL 核心数据库表全景结构                    │
├────────────────────────────────┬───────────────────────────────────────┤
│ 1. 质量检验核心表              │ 2. 不合格待审与 MRB 评审              │
│    - inspection_orders         │    - pending_mrb_items                │
│    - inspection_items          │    - mrb_orders                       │
│    - inspection_measured_values│    - mrb_signoffs                     │
│    - inspection_defects        │                                       │
├────────────────────────────────┼───────────────────────────────────────┤
│ 3. 质检方案与分类继承          │ 4. 炉批号与批次追溯 (DAG)             │
│    - inspection_plans          │    - quality_lots                     │
│    - inspection_plan_items     │    - lot_relations                    │
│    - inspection_plan_material_links                                    │
├────────────────────────────────┼───────────────────────────────────────┤
│ 5. 生产放行与打印报表          │ 6. 基础档案与 PBAC 数据权限           │
│    - release_gates             │    - sys_users / sys_roles            │
│    - report_templates          │    - user_data_permissions (PBAC)     │
│                                │    - master_inventory_categories      │
│                                │    - master_materials / master_suppliers│
├────────────────────────────────┴───────────────────────────────────────┤
│ 7. 扩展注册中心与事务集成                                              │
│    - process_settings (工艺路线与参数库)                               │
│    - external_outsourced_registries (委外13张表注册中心)              │

│    - audit_logs (Append-Only 不可篡改审计日志)                         │

```

## 2. 核心表结构物理字段定义

### 2.1 检验单主表 (`inspection_orders`)
| 字段名 (Column) | 物理类型 (Type) | 约束 / 默认值 | 业务定义与说明 |
|:---|:---|:---|:---|
| `id` | `VARCHAR(36)` | PK | UUID v4 主键 |
| `inspection_no` | `VARCHAR(64)` | UNIQUE, NOT NULL | 检验单号（IQC/IPQC/OUT/OQC-日期-序号） |
| `type` | `VARCHAR(32)` | NOT NULL | 检验类型：`IQC`, `IPQC`, `OUTSOURCED`, `OQC` |
| `status` | `VARCHAR(32)` | NOT NULL, DEFAULT 'PENDING' | 状态：`DRAFT`, `PENDING`, `INSPECTING`, `PASS`, `FAIL`, `REJECTED`, `CONCESSION`, `CANCELLED` |
| `source_order_no` | `VARCHAR(64)` | INDEX | 来源外部单号（采购单号/工单号/委外单号/出库单号） |
| `material_code` | `VARCHAR(64)` | NOT NULL, INDEX | 物料编码 |
| `material_name` | `VARCHAR(255)` | NOT NULL | 物料品名 |
| `material_spec` | `VARCHAR(255)` | NULL | 规格型号 |
| `inventory_category` | `VARCHAR(64)` | NOT NULL, INDEX | 存货分类编码（PBAC 权限过滤基石） |
| `supplier_code` | `VARCHAR(64)` | NULL, INDEX | 供应商/外协厂商代码 |
| `supplier_name` | `VARCHAR(255)` | NULL | 供应商/外协厂商全称 |
| `customer_code` | `VARCHAR(64)` | NULL, INDEX | 客户代码（针对 OQC） |
| `customer_name` | `VARCHAR(255)` | NULL | 客户名称 |
| `arrival_qty` | `NUMERIC(14,4)` | NOT NULL | 报检/到货总量 |
| `sample_qty` | `NUMERIC(14,4)` | NOT NULL | AQL 抽样件数 |
| `qualified_qty` | `NUMERIC(14,4)` | DEFAULT 0 | 合格件数 |
| `unqualified_qty` | `NUMERIC(14,4)` | DEFAULT 0 | 不合格件数 |
| `inspector_id` | `VARCHAR(36)` | NULL | 检验员用户 ID |
| `inspector_name` | `VARCHAR(64)` | NULL | 检验员姓名 |
| `heat_no` | `VARCHAR(64)` | NULL, INDEX | **原材料熔炼炉批号 (Heat Number)** |
| `batch_no` | `VARCHAR(64)` | NULL, INDEX | 生产流转/出货批次号 |
| `plan_id` | `VARCHAR(36)` | NULL | 绑定的质检方案 ID |
| `plan_snapshot` | `JSONB` | NOT NULL | **方案指标快照**（深拷贝，防篡改） |
| `external_metadata` | `JSONB` | DEFAULT '{}' | **外部委外13张表挂载字段**（槽号/膜厚/化验） |
| `version` | `INTEGER` | NOT NULL, DEFAULT 1 | 乐观锁版本号 |
| `created_at` | `TIMESTAMPTZ` | DEFAULT NOW() | 单据创建时间 |
| `updated_at` | `TIMESTAMPTZ` | DEFAULT NOW() | 最后更新时间 |
| `work_order_no` | `VARCHAR(64)` | NULL, INDEX | MES 生产工单号 (IPQC 过程检验专用) |
| `blanking_length` | `NUMERIC(10,3)` | NULL | 下料/断料长度 mm (IPQC_CT 下料首巡检专用) |
| `operator_name` | `VARCHAR(64)` | NULL | 操作员姓名 (下料/滚丝工序机台作业员) |
| `operator_id` | `VARCHAR(64)` | NULL | 操作员工号 |
| `equipment_code` | `VARCHAR(64)` | NULL, INDEX | 生产机台设备编号 (如 1#冷镦机/EQ-001) |
| `equipment_name` | `VARCHAR(128)` | NULL | 设备名称 (如 全自动高速冷镦机、精密滚丝机) |
| `thread_spec` | `VARCHAR(64)` | NULL | 牙纹/螺纹规格 (IPQC_RL 滚丝检验专用，如 M12*1.25, 6g) |
| `inspection_team` | `VARCHAR(64)` | NULL | 终检班组 (IPQC_FN 成品检专用，如 终检一组) |
| `process_step` | `VARCHAR(64)` | NULL | 工序名称/阶段 (如 自动断料、手工滚牙、检测入库) |
| `completed_at` | `TIMESTAMPTZ` | NULL | 检验终判完成时间 |
| `sales_order_no` | `VARCHAR(64)` | NULL, INDEX | 销售出库单号 (008 出货检验 OQC_SH 专用，如 SO-20260706-01) |
| `dispatch_date` | `VARCHAR(32)` | NULL | 出库日期 (008 出货检验 OQC_SH 专用，如 2026-07-06) |
| `customer_name` | `VARCHAR(255)` | NULL, INDEX | 客户名称 (008 出货检验 OQC_SH 专用) |
| `sales_order_po_no` | `VARCHAR(64)` | NULL | 客户采购订单号/合同号 (008 出货检验 OQC_SH 专用，如 PO-A-001) |
| `erp_status` | `VARCHAR(32)` | NULL | ERP 出库单审核状态：待审核 / 已审核 / 已拦截 (008 出货检验 OQC_SH 专用) |
| `outsource_no` | `VARCHAR(64)` | NULL, INDEX | ERP 委外加工单号 (009 委外检验台账专用，如 WW-20260706-010) |
| `process_type` | `VARCHAR(64)` | NULL, INDEX | 加工类型/工艺分类：镀锌/镀镍/发黑/磷化/达克罗/热处理/机加工 (009 委外检验专用) |
| `return_date` | `VARCHAR(32)` | NULL | 委外件回厂登记日期 `YYYY-MM-DD` (009 委外检验专用) |
| `vendor_name` | `VARCHAR(255)` | NULL | 加工商名称快照 (009 委外检验专用)。历史行由 011 迁移按 `supplier_code → suppliers.supplier_name` 回填；缺失时才回落展示 `supplier_code` |

- **索引优化**：
  - `idx_inspections_category_created`: `(inventory_category, created_at DESC)`（PBAC 范围扫描）
  - `idx_inspections_heat_no`: `(heat_no)`（炉批号追溯极速定位）
  - `idx_inspections_status_type`: `(status, type)`（看板聚合加速）
  - `idx_inspection_orders_outsource_no` / `idx_inspection_orders_process_type`: 委外加工单号与加工类型台账检索

> 委外检验（`OQC_SF` / `OQC_MACH` / `OQC_HEAT` 等委外工艺分类）四个台账字段的完整字段口径、
> 后端契约、仓储映射与前端消费规则见 `docs/15-委外检验OQC数据字段与接口打通设计.md`。
  - `idx_inspection_orders_sales_order_no` / `idx_inspection_orders_customer_name`: `(sales_order_no)` / `(customer_name)`（008 出货检验台账按出库单号、客户检索加速）

### 2.4 MRB 评审主表 (`mrb_orders`) 与会签表 (`mrb_signoffs`)
- **`mrb_orders`**：
  - `mrb_no`: UNIQUE NOT NULL (`MRB-YYYYMMDD-XXXX`)
  - `inspection_order_id`: 关联检验单
  - `status`: `DRAFT`, `PENDING`, `APPROVED`, `REJECTED`
  - `disposition_type`: `SCRAP` (报废), `REWORK` (返工), `RETURN` (退货), `CONCESSION` (特采放行)
  - `root_cause`: 根因分析（人机料法环）
  - `corrective_action`: 纠正预防措施 (CAPA)
  - `cost_impact`: 预估质量经济损失
- **`mrb_signoffs`**：
  - `department`: `QUALITY`, `ENGINEERING`, `PRODUCTION`, `PURCHASING`
  - `signer_id` / `signer_name`: 会签人员
  - `decision`: `ACCEPT`, `REJECT`, `NEEDS_DISCUSSION`
  - `comment`: 审批意见
  - `signed_at`: 签字时间戳

---

### 2.5 批次血缘谱系表 (`quality_lots` 与 `lot_relations`)
- **`quality_lots`**：
  - `lot_no`: 批次唯一标识（主键或唯一索引）
  - `heat_no`: **金属原材料熔炼炉批号**
  - `material_code`: 物料编码
  - `node_type`: 节点类型：`RAW_MATERIAL` (原料), `WIP` (在制品), `OUTSOURCED` (委外), `FINISHED_GOOD` (成品)
- **`lot_relations`**：
  - `parent_lot_id` -> `child_lot_id`: 构建 DAG 有向无环图
  - `relation_type`: `TRANSFORM` (生产转化), `OUTSOURCE` (外协加工), `ASSEMBLE` (多合一组装)
  - `process_code`: 转化发生的工序编码

### 2.7 扩展注册中心与系统集成表
- **`process_settings` (工艺参数字典)**：
  - `process_code`: 工序代码
  - `parameter_definitions`: JSONB 结构（定义该工序关键质检要求，如切削速度、刀具编号、热处理升温曲线等）
- **`external_outsourced_registries` (委外表注册中心)**：
  - `category_type`: 委外类型（`ELECTROPLATING`, `HEAT_TREATMENT` 等）
  - `field_mappings`: JSONB 结构（将外部 13 张表的物理列动态映射为 QMS 归一化字段）
- **`outbox_events` (事务发件箱)**：
  - `aggregate_type`: 聚合根类型（`INSPECTION`, `MRB`）
  - `event_type`: 事件名称（`INSPECTION_PASSED`, `CONCESSION_GRANTED`）
  - `payload`: JSONB 业务负载
  - `status`: `PENDING`, `PUBLISHED`, `FAILED`
  - `retry_count`: 重试计数
- **`audit_logs` (不可篡改审计日志)**：
  - `diff_patch`: JSONB 结构（RFC 6902 JSON Patch 格式，记录所有变更字段的前后差异）

## 3. 核心 JSONB 模式定义规范 (JSON Schemas)

### 3.1 方案快照 `plan_snapshot`
```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": ["plan_id", "plan_code", "version", "items"],
  "properties": {
    "plan_id": { "type": "string" },
    "plan_code": { "type": "string" },
    "version": { "type": "integer" },
    "items": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["characteristic_name", "target_value", "usl", "lsl", "measuring_tool"],
        "properties": {
          "characteristic_name": { "type": "string" },
          "target_value": { "type": "number" },
          "usl": { "type": "number" },
          "lsl": { "type": "number" },
          "unit": { "type": "string" },
          "measuring_tool": { "type": "string" },
          "aql_level": { "type": "string" },
          "is_critical": { "type": "boolean" }
        }
      }
    }
  }
}
```
