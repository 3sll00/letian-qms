| 项 | 口径 |

### 2.3 留痕表 `outsource_reference_renumberings`

```sql
id uuid pk, order_id uuid, order_no varchar(64), kind varchar(16)  -- 'OUTSOURCE_NO' | 'BATCH_NO'
old_value varchar(64), new_value varchar(64), note varchar(255), migrated_at timestamptz
```

## 3. Q2：两条 2023 历史行的「无对账单」语义

- **不补号**：`external_document_mappings` 本机 0 行，ERP 侧无从核对；补一个 ERP 单号属于伪造，且会通过 `subcontractNo` 打到制造证书上（与 `docs/33` §2.4 刚建立的「证书不编造」口径直接冲突）。
- **显式语义**：台账「委外加工单号」列缺值仍渲染 `—`，但增加 `title` 提示「ERP 无委外加工单（历史导入行）」；委外表单「委外加工单号」栏保持留空 + 占位提示。
- **文档收口**：本条由「待业务确认」改为**已定口径**；若后续拿到 ERP 对账单，再按 `docs/31` 先例做一次回填迁移（留痕表可直接承载 `kind='OUTSOURCE_NO'` 的补号记录）。

| 中性盐雾 | 盐雾 / NASS / NSS / 耐腐蚀 | 同上 |

| 表面硬度 | 表面硬度 / HV | 同上 |

## 5. L2 / L3：证书去编造（质量证书 + 制造证书）

### 5.1 质量证书（IQC / IPQC / OQC_SH）

| 字段 | 变更前 | 变更后 |
|:---|:---|:---|
| `certNo` | `QC-IQC-` + 单号里抠出来的数字（无单号时硬编码 `20241101`） | 有单号：`QC-{orderNo}`；无单号：空 |
| `issueDate` | 无值取今天 | 不变（生成本证书的动作真实发生在今天） |
| `customer` / `supplier` / `contractNo` / `productName` / `specification` / `heatNo` / `batchNo` / `quantity` / `surfaceFinish` / `standard` / `performanceGrade` | 各带编造默认值 | 只取真实字段，无值留空 |
| `steelGrade` | `detectSteelGrade()` 猜不中即回落 `ML40Cr` | 猜不中即**空** |
| `chemicalComposition` / `mechanicalProperties` / `dimensions` | 无 `items` 时由 `getVariation()` 生成「看起来像实测」的假值 | 只读工单 `items` 的真实实测项；无数据即空数组，模板分区不渲染 |
| `inspector` / `reviewer` / `approver` | `陈静 (IQC-08)` / `张强 (QA-01)` / `王国荣 (总工)` | 只取真实字段，无值留空（签核栏留白待签） |
| `notes` | 一段编造的检验结论文案 | 只取 `inspectionNotes`，无值不打印 |

### 5.2 制造证书（委外）

- 模板内硬编码的 **Decision `PASS`**（8 处）、外观行 **规范要求** 与 **实测结果** `Conformed (良好无缺陷)`、印章 **`PASSED 3.1`** 全部改为读数据：
  - 每行 Decision 取该行的 `decision`（由表单按方案指标判定后写入，未判定即空白）；
  - 外观行规范要求取方案驱动的规范文本、实测结果取外观实测记录；
  - 印章结论取整单判定（`overallDecision`），未判定则不打印结论字样。
- 模板版式常量（中英文标签、企业抬头、`EN 10204 Type 3.1 Certified Document` 版尾）保留——它们不冒充任何检验事实。

### 5.3 证书调用侧的键名与兜底（IQC / IPQC，实测发现的补收口）

模板与服务去编造之后，**调用侧**还留着两类问题（本轮 CDP 走查实测暴露）：

| 调用侧 | 问题 | 处置 |
|:---|:---|:---|
| `IqcList.handleOpenCert` | 单号写进 `id` 键，而 builder 读 `orderNo` / `docNo` → **证书编号与弹窗标题恒空白**（`质量保证证书预览 ()`）；`furnaceNo: item.furnaceNo \|\| item.batchNo` → **把批号当炉号打印**（`炉号 / 批号` 显示 `B20231012-01 / B20231012-01`）；`inspectDate: item.inboundDate` → 把**入库日期**当证书签发日期 | 改传 `orderNo`；炉号只认 `furnace_heat_batch_no`；不再传 `inspectDate`（由 `certIssueDate` 取「今天」） |
| `IpqcViews.handleOpenCert` | 同样的 `id` 键错位；另有 5 处 `\|\|` 兜底：`spec \|\| '标准紧固件'`、`quantity \|\| 100 件`、`sampleQty \|\| 32`、`\|\| '2026-09-20'`、`conclusion: isFail ? 'FAIL' : 'PASS'`（给未判定单补 PASS） | 一律只下发库中真实值，无值留白；删除派生 `passQty` / `failQty` / `conclusion` |
| `QualityCertificateTemplate` | `炉号 / 批号` 单元格固定 `{heatNo} / {batchNo}`，炉号为空时打印成 ` / B20231012-01` | 改为只拼非空值（`[heatNo, batchNo].filter(...).join(' / ')`） |

> 口径同 §1：**能用真实来源的一律接真实来源；没有真实来源的一律留空**。调用侧的 `\|\|` 兜底与键名错位同属「看起来有值、其实是编造或错源」，必须一并收口。

## 6. L5 / L6：台账入口与写路径

### 6.1 L5 行级证书入口

`OutsourceList` 操作列在「检验/继续」「详情」之后新增「证书」按钮 → `handleOpenCert(item)`。

### 6.2 L6 写路径

| 场景 | 触发 | 请求 |
|:---|:---|:---|
| 存量单录入 | 列表「检验 / 继续」（`onInspect(item, false)`） | ① `POST /inspections/{id}/submit-measurements`（`items` 取方案命中行，逐行 `measuredVal` 或 `measuredText`，空行不下发）；② `POST /inspections/{id}/status`（终判 `PASSED`/`FAILED` + 检验人 + 判定评语 + 完成时间） |
| 新建单 | 表单在无 `id` 时提交 | ① `POST /inspections`（`inspectionType` / `materialCode` / `batchNo` / `sampleQty` / `totalQty` / `outsourceNo` / `processType` / `vendorName` / `specification` / `unit` / `inspectorName` / `planVersionId`）；② 复用上表的实测与终判 |

- 提交按钮在请求期间禁用并显示「提交中…」，失败用 `errorMessage(err)` 就地红字提示（不再 `alert` 假成功）。
- 成功后回调 `onSubmit(result)`（父页用于退出表单），并提示服务端返回的检验单号。
- 数量解析：表单「交付数量」形如 `500 PCS`，提交时取数值部分作为 `sampleQty` / `totalQty`，非数值则不下发。

### 6.3 L6b：「5 点膜厚」与方案指标行的同一指标口径

表单里「表面处理膜厚 5 点测试」与方案指标清单的「镀层厚度」是**同一指标的两个录入入口**（前者是车间惯用的 5 点法，后者是方案指标本体）。旧实现在两者之间没有桥，只填 5 点时：

- 指标行 `actual` 仍为空 → `judgeIndicatorRow()` 判不出结论 → 膜厚判定徽标与指标清单汇总停在「待判定」；
- 制造证书打印 5 点平均实测值，但 Decision 列空白；
- 提交时 `measuredRows` 为空 → **库里一个数都没落**（静默丢数，最严重的一条）。

收口口径由三个派生量承载（`thicknessPointActual` / `planRowsForJudge` / `thicknessRowForJudge`）：

| 场景 | 判标 / 证书 / 落库取值 |
|:---|:---|
| 指标行实测值留空、5 点有值 | 5 点平均值（`avgThickness.toFixed(1)`）充当该指标行实测值 |
| 指标行实测值有值 | **以显式录入为准**，5 点均值不覆盖 |
| 两者都空 | 保持未判定（空白 + 「未判定」徽标），不编造 |

同一口径贯穿四处：膜厚判定徽标、指标清单汇总（`summarizeJudgements`）与单项判定列、制造证书 Decision、提交下发的 `measuredVal`。
