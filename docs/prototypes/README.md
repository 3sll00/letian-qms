## 规范与使用守则

1. **原型权威性**：所有前端页面组件命名、表格列排布、状态徽标颜色、筛选交互均以此 21 张设计图为第一基准。
2. **多模态索引**：配合 `docs/requirements/ocr_result.txt` 可快速检索原型图中的字段命名与指标字面值。
