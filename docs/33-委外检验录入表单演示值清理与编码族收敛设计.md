## 2. Q6：委外检验录入表单演示值清理

### 2.1 口径（唯一权威）

1. **抬头字段只由真实数据源填充**：优先台账列表行（`OutsourceListItem`），只读回看时以本单方案快照
   （`GET /inspections/{id}` → `InspectionOrder`）为准；两者都没有来源的字段**保持空串**，由录入人填写。
2. **列表占位符 `-` 不是数据**：列表行用 `-` 表示「无值」，回填时必须还原为空串（`fromList()`），
   否则录入人会把占位符当成已填内容，甚至原样提交 / 打印。
3. **检验日期默认「今天」**：录入动作真实发生日，不是编造的固定演示日期。
4. **实测值不进表单默认值**：会在制造证书上被打印成「已测出结果」的实测记录与结论，一律清空，
   由录入人按检验动作现场填写；「技术规范要求」文本属录入规范项（与方案指标行的「标准要求」同性质），本轮保留。
5. **不给未发生的判定**：判定评语不预置「判定合格」文案；质量负责人是签核动作，表单本身无真实签核数据源，
   一律留空（禁用输入框 + 占位提示「待质量负责人签核」）。

## 4. Q4：`CAT-FIN-MACH` 分类归位（迁移 `027`）

### 4.1 现状与语义

| 物料 | 名称 | 变更前分类 | 变更后分类 |
|:---|:---|:---|:---|
| `MAT-SLV-45-20-30` | 精密轴套（Φ20×30mm / 45# 钢 / 精磨外圆） | `CAT-FIN-BOLT` 高强度螺栓类 | `CAT-FIN-MACH` 机加工成品件 |
| `MAT-CON-M12` | 连接件（M12 连接件 / 机加工成品） | `CAT-FIN-BOLT` 高强度螺栓类 | `CAT-FIN-MACH` 机加工成品件 |

两者是**委外机加工回来的成品件**（009 委外检验机加工页签受托件），既非螺栓亦非螺母，
挂在「高强度螺栓类」是原型遗留的口径错位。

### 4.2 迁移 `027_unify_machined_material_category.ts`

新增 `packages/infrastructure/src/migrations/027_unify_machined_material_category.ts`（已注册 `runner.ts`），
同一事务内：

1. 建留痕表 `material_category_reassignments`（`material_code` / `old_category_code` / `new_category_code` / `note` / `migrated_at`，长期留痕 + `down()` 依据）；
2. `INSERT inventory_categories` 新增 `CAT-FIN-MACH`（机加工成品件，`parent_code = CAT-FINISH`，`level = 2`），幂等（`ON CONFLICT`）；
3. 按**固定字典**把 2 条物料的 `category_code` 归位（字典是决策，不从数据推导）；
4. 打印本次改分类的行数与分类总数。

`down()`：按留痕表把分类还原，再删除 `CAT-FIN-MACH` 分类行（留痕表不存在则整段 no-op）。

### 4.3 PBAC 同步（口径：可见范围保持等价）

`material_permissions.materialCategories` 走**精确 `IN` 匹配**（`pbac-sql-translator.ts`，无父子继承展开），
因此把 2 条物料移出 `CAT-FIN-BOLT` 会让「成品类」授权角色失去它们。为保持权限可见范围**等价**，
迁移同时把 `CAT-FIN-MACH` 追加进「分类白名单含 `CAT-FIN-BOLT` 且用于成品件授权」的规则：

| 规则 | 角色 | 变更前白名单 | 变更后白名单 |
|:---|:---|:---|:---|
| `70000000-…-0003`（刘芳） | `OQC_INSPECTOR` | `['CAT-FINISH','CAT-FIN-BOLT']` | `['CAT-FINISH','CAT-FIN-BOLT','CAT-FIN-MACH']` |

同步面：`seeds/data.ts`（分类 9 → **10** 行、2 条物料分类、规则 3 白名单）、
`scripts/testing/mrb-wiring-verify.cjs`（刘芳白名单数组同步）、`docs/18`、`docs/03`。
